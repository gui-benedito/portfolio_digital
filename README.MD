## 📌 Sobre o Portfólio

Este projeto consolida a trajetória formativa e profissional de Guilherme dos Santos Benedito, estruturado conforme as diretrizes acadêmicas oficiais de DSM da FATEC São José dos Campos (`orientacoes_portfolio_dsm_2026_02.pdf`).

O portfólio destaca competências técnicas (**Hard Skills**) e socioemocionais (**Soft Skills**) desenvolvidas em **Aprendizagem por Projetos Integrados (API)** para clientes reais, bem como projetos profissionais e publicações científicas de relevância internacional.

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Compilar versão de produção
npm run build
```

---

## 🌐 Deploy no GitHub Pages

O deploy é automatizado via GitHub Actions sempre que um push é realizado na branch `main`.
Para ativar no repositório:
1. Acesse **Settings** > **Pages** no seu repositório no GitHub.
2. Em **Build and deployment > Source**, selecione **GitHub Actions**.
